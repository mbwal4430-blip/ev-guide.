Frequently asked questions

How fast is the Model S Plaid?

This guide lists it at 1.99 seconds from 0 to 60 mph, with 1,020 horsepower and a 200 mph top speed.

What is the estimated range of each Tesla model?

About 396 miles for the Model S Plaid and roughly 300 to 330 miles for the Model 3, Model Y, Model X and Cybertruck.

The Model X is listed with seven seats and falcon-wing doors.
